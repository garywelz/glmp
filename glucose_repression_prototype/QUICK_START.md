# 🚀 Quick Start Guide

## View the Prototype in 30 Seconds

### **Option 1: Interactive Viewer** (Recommended)
1. Open `viewer.html` in any web browser
2. Click zoom level buttons to explore
3. That's it! No installation needed.

### **Option 2: View Mermaid Diagrams**
1. Copy contents of `process.mmd`
2. Paste into https://mermaid.live
3. See the flowcharts rendered

### **Option 3: Read the Data**
1. Open `README.md` - complete documentation
2. Open `metadata.json` - structured data
3. Open `citations.json` - all references
