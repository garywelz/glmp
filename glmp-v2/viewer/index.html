About GLMP

The Genome Logic Modeling Project

GLMP applies programming concepts to biological processes, representing them as computational flowcharts with decision points, loops, and conditional logic.

Methodology

Each process is:

  • Researched from primary literature
  • Modeled as a Mermaid flowchart
  • Verified for accuracy
  • Cited with proper sources (PubMed, DOI)
  • Reviewed for clarity and completeness

Technology

This viewer uses:

  • Mermaid.js for interactive diagrams
  • Vanilla JavaScript for simplicity and performance
  • JSON for portable, structured data
  • Static hosting on Google Cloud Storage

Citation

If you use GLMP in your research, please cite appropriately and link to the source.
