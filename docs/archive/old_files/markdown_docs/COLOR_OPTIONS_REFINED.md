# Refined Color Options - Avoiding Purple Conflict

## Current AND Gate Color:
- **AND Logic Gates:** `#7950f2` 🟣 Deep Purple/Indigo

## Problem with Option A:
- **Intermediates:** `#e1bee7` 🟣 Light Purple/Lavender
- **Too close to AND gate purple!** ❌

## Better Alternatives for Intermediates:

### Option 1: Light Blue/Cyan (RECOMMENDED)
- **Color:** `#81d4fa` 🔵 Light Cyan/Sky Blue
- **Why:** Distinct from all others, calming/neutral feeling
- **Contrast:** Good separation from Sky Blue `#74c0fc` and Purple `#7950f2`

### Option 2: Light Pink
- **Color:** `#ffb3ba` 🩷 Soft Pink
- **Why:** Completely different family, warm but not orange
- **Contrast:** Totally distinct from all existing colors

### Option 3: Pale Yellow/Cream
- **Color:** `#fff9c4` 💛 Pale Yellow
- **Why:** Very light, neutral, works with yellow enzymes
- **Contrast:** Lighter than enzyme yellow, readable with black text

### Option 4: Light Teal
- **Color:** `#80deea` 🩵 Light Teal/Aqua
- **Why:** Between green and blue, unique position
- **Contrast:** Distinct from green triggers and blue processing

### Option 5: Pale Peach
- **Color:** `#ffe0b2` 🍑 Pale Peach
- **Why:** Warm but much lighter than orange/amber
- **Contrast:** Won't confuse with OR gates or enzymes
